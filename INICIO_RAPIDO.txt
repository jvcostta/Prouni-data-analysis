   📊 COMO RODAR O PROJETO - ProUni Dashboard
═══════════════════════════════════════════════════════════════

🎯 OBJETIVO: Visualizar dados do ProUni (2018-2020) em um dashboard interativo

═══════════════════════════════════════════════════════════════
   PASSO 1: PROCESSAR OS DADOS
═══════════════════════════════════════════════════════════════

   👆 Clique duas vezes em:
   
      📄 processar_dados.bat
   
   O que acontece:
   ✓ Carrega dados de 2018, 2019 e 2020
   ✓ Limpa e padroniza os dados
   ✓ Unifica tudo em um único arquivo
   ✓ Salva em: data/processed/
   
   ⏱️ Tempo: ~30 segundos
   
   ⚠️  Execute isso apenas UMA VEZ ou quando adicionar novos dados

═══════════════════════════════════════════════════════════════
   PASSO 2: INICIAR O DASHBOARD
═══════════════════════════════════════════════════════════════

   👆 Clique duas vezes em:
   
      📄 iniciar_dashboard.bat
   
   O que acontece:
   ✓ Ativa o ambiente virtual Python
   ✓ Inicia o servidor do dashboard
   ✓ Abre na porta 8050
   
   Você verá:
   
      🚀 Iniciando Dashboard ProUni
      ====================================
      📍 Acesse: http://localhost:8050
      ⚠️  Pressione CTRL+C para encerrar
   
═══════════════════════════════════════════════════════════════
   PASSO 3: ACESSAR O DASHBOARD
═══════════════════════════════════════════════════════════════

   🌐 Abra seu navegador e acesse:
   
      http://localhost:8050
   
   OU
   
   Se o navegador não abrir automaticamente, copie e cole
   o endereço acima na barra de endereços.

═══════════════════════════════════════════════════════════════
   🎨 O QUE VOCÊ VERÁ NO DASHBOARD
═══════════════════════════════════════════════════════════════

   📊 FILTROS NO TOPO:
   ├─ 📅 Ano (2018, 2019, 2020, Todos)
   ├─ 🗺️ Estado (SP, MG, RJ, etc.)
   ├─ 🎓 Tipo de Bolsa (Integral, Parcial)
   ├─ 📚 Modalidade (Presencial, EAD)
   └─ 🔍 Busca por nome do curso
   
   📈 CARDS COM NÚMEROS:
   ├─ Total de Bolsas
   ├─ Bolsas Integrais
   ├─ Bolsas Parciais
   └─ Número de Instituições
   
   📊 GRÁFICOS INTERATIVOS:
   ├─ Evolução ao longo dos anos
   ├─ Top 15 estados com mais bolsas
   ├─ Top 15 cursos mais procurados
   └─ Proporção Integral vs Parcial
   
   📋 TABELA:
   └─ Detalhes dos dados filtrados

═══════════════════════════════════════════════════════════════
   ❓ PROBLEMAS COMUNS
═══════════════════════════════════════════════════════════════

   ❌ Erro: "Dados não encontrados"
   ✅ Solução: Execute novamente o processar_dados.bat
   
   ❌ Erro: "Module not found" 
   ✅ Solução: Abra o PowerShell e execute:
      .\venv\Scripts\Activate.ps1
      pip install -r requirements.txt
   
   ❌ Dashboard não abre no navegador
   ✅ Solução: Abra manualmente: http://localhost:8050
   
   ❌ Porta 8050 já está em uso
   ✅ Solução: Feche outros dashboards ou altere a porta no app.py
